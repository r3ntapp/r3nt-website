# R3NT company website (www.r3nt.co)

Plain static site — no build step, no JavaScript, no cookies, no tracking.
Published from the public repository `r3ntapp/r3nt-website` on GitHub Pages,
custom domain `www.r3nt.co` (see `CNAME`). The apex `r3nt.co` is redirected to
`www` by GitHub Pages once its A records point at GitHub.

Pages: `/` (company), `/privacy/`, `/terms/`, `404.html`.
Company details shown are from Companies House (R3NT LIMITED, 16462865).
